Step 3 — Fonts & Text Styles
Step 03

Set Fonts in Brand Kit

In the Fonts section, set three text style slots. Both fonts are available in Canva's library — search by name.

Slot Font Weight Size Used for
Heading Orbitron 900 (Black) 42 pt Page titles, hero h1, brand name, CTAs
Subheading Orbitron 800 (ExtraBold) 26 pt Section titles, plan names, stat numbers
Body Exo 2 400 (Regular) 15 pt Paragraphs, descriptions, feature lists

Canva won't show font weights in the size picker — after selecting Orbitron for Heading, manually set Bold/Extra Bold in the text panel. For Exo 2 body, leave at Regular.

Step 5 — Brand Name Rules
Step 05

Brand Name Styling Rules

How "Innovat3" appears depends on context. Use the table below whenever writing the name in Canva designs.

ContextCasingColourNotes
Logo / navinnovat3.#F97316Lowercase + trailing period
Hero headingsInnovat3#FFFFFFCapital I — no period
Inline / copyInnovat3contextualCapital I — no period
Legal / trademarkINNOVAT3#F97316All caps
Tagline pairinginnovat3.#F97316Always paired with tagline below

The "3" replaces the letter e in "innovate" — it is always the digit 3, never the letter e. In two-colour treatments, "INNOVAT" is orange and "3" is white.
