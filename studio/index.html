innovat3.Tag Studio — secure IDs · QR sticker sheets · NFC writing

1 · Create a batch

New IDs are random (IN3-YYYY-XXXXXX, about 1 billion combinations) so nobody can guess someone else's tag. Old 4-digit IDs still work but are guessable — replace them when you can.

2 · 3D print plates — QR printed in black on the tag

Preview of tag #1 from the top. One STL per plate, all tags already unique. In Bambu Studio add a colour change to black at the first layer above the QR start height (and a pause to drop in the NFC inlay) — exact layers are in the README inside the zip. Module size under 0.8 mm needs a 0.2 mm nozzle.

3 · Paper labels (optional — packaging / activation cards)

Print at 100% / Actual size.

4 · Write NFC (Android + Chrome)

NFC writing works only in Chrome on an Android phone, with this page opened from your website (https). On a PC, use this page to print; open it on your phone to write tags. Fallback: free NFC Tools app → Write → URL → paste the link from the table → then Other → Lock tag.
