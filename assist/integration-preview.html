How it works
1
Tag is scanned — the emergency card opens exactly as it does today. Nothing about the card changes. Blood type, contacts, medical alerts are all still front and centre.
2
Teal "AI Medical Assistant" button appears below the emergency numbers. A bystander, paramedic, or the tag owner can tap it if they need guidance or want to find nearby help.
3
Assistant opens — voice-guided first aid for 12+ emergencies, tap-to-call emergency numbers, and a real-time facility finder using GPS. No app, no login, works on any phone.
4
Works on pet tags too — the same assistant button can be added to the pet card for owners who find a lost or injured animal and need vet finder or animal emergency guidance.
5
Zero extra cost — voice is pre-recorded (committed to the repo as MP3 files), facility search uses OpenStreetMap (free), no API calls at runtime.
